## US11 — Painel Financeiro por Cliente

**User Story:** "Como Financeiro, quero acessar um painel com a visão consolidada dos clientes, visualizando valor contratado, custo real e lucro por cliente, para acompanhar o desempenho financeiro da empresa."

<details>
<summary>Critérios de Aceitação</summary>

- O sistema deve exibir o detalhamento de cada cliente com valor contratado, custo real e lucro.
- O painel é somente leitura e acessível apenas pelo perfil Financeiro.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Financeiro acessa o Painel Financeiro**

- Dado que sou um Financeiro autenticado;
- Quando acesso o Painel Financeiro;
- Então devo ver o detalhamento por cliente com os dados calculados corretamente.

**Cenário 2: Lucro negativo**

- Dado que o custo real de um cliente ultrapassou o valor contratado;
- Quando acesso o Painel Financeiro;
- Então o lucro daquele cliente deve ser exibido em vermelho.

</details>

<details>
<summary>Regras de Negócio</summary>

- O Painel Financeiro é acessível apenas pelo perfil Financeiro.
- O lucro é calculado como: valor contratado — custo real acumulado (apenas apontamentos aprovados).
- O painel é somente leitura.

</details>

<details>
<summary>Dicionário de Dados</summary>

## Dicionário de Dados — US11

### Painel Financeiro por Cliente

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| idCliente | Cliente exibido no painel | Integer | - | FK, Not Null |
| nomeCliente | Razão social do cliente | String | 255 | Not Null |
| totalProjetosAtivos | Quantidade de projetos ativos vinculados ao cliente | Integer | - | Calculado |
| valorContratadoTotal | Soma dos valores contratados dos projetos do cliente | Decimal | (15,2) | Calculado |
| custoRealTotal | Soma do custo real acumulado dos projetos do cliente | Decimal | (15,2) | Calculado |
| lucro | Diferença entre valor contratado total e custo real total | Decimal | (15,2) | Calculado |
| margemPercentual | Percentual de lucro sobre o valor contratado | Decimal | (5,2) | Calculado |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Indicadores definidos** | Confirmados valor contratado, custo real, lucro e margem por cliente. |
| **Regra de cálculo definida** | Confirmado que lucro = valor contratado — custo real (apenas apontamentos aprovados). |
| **Dependências resolvidas** | US09 e US10 entregues — custos e clientes já existem no sistema. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Restrição de acesso verificada** | Apenas o perfil Financeiro acessa o Painel Financeiro. |
| **Cálculos corretos** | Lucro e margem calculados corretamente com base nos apontamentos aprovados. |
| **Painel somente leitura** | Nenhum dado pode ser editado a partir do Painel Financeiro. |

</details>

## US10 — Gestão de Clientes

**User Story:** "Como Gestor, quero cadastrar e editar clientes com seus dados de identificação e vinculá-los a projetos existentes, para que o Financeiro possa acompanhar o desempenho financeiro por cliente."

<details>
<summary>Critérios de Aceitação</summary>

- O sistema deve permitir o cadastro e edição de clientes com nome, CNPJ, email e telefone.
- O sistema deve permitir vincular projetos a um cliente.
- Não deve ser possível cadastrar dois clientes com o mesmo CNPJ.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Cadastro de cliente com sucesso**

- Dado que sou um Gestor e estou na tela de cadastro de clientes;
- Quando preencho todos os campos obrigatórios e confirmo o cadastro;
- Então o sistema deve salvar o registro e exibir o cliente na listagem.

**Cenário 2: Tentativa de cadastro com CNPJ duplicado**

- Dado que já existe um cliente com o CNPJ informado;
- Quando tento cadastrar outro cliente com o mesmo CNPJ;
- Então o sistema deve bloquear o cadastro e exibir mensagem de CNPJ já cadastrado.

</details>

<details>
<summary>Regras de Negócio</summary>

- Apenas o Gestor pode cadastrar e editar clientes.
- CNPJ deve ser único no sistema.
- Um projeto pode estar vinculado a no máximo um cliente.

</details>

<details>
<summary>Dicionário de Dados</summary>

## Dicionário de Dados — US10

### Cliente

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| id | Identificador único do cliente | Integer | - | PK, Not Null |
| nome | Razão social do cliente | String | 255 | Not Null |
| cnpj | CNPJ do cliente | String | 18 | Not Null, Unique |
| email | E-mail de contato do cliente | String | 255 | Not Null |
| telefone | Telefone de contato do cliente | String | 20 | Nullable |
| dataCriacao | Data de criação do registro | Timestamp | - | Not Null |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Campos de cliente definidos** | Nome, CNPJ, email e telefone estão definidos e validados. |
| **Regra de CNPJ único definida** | Confirmado que não é permitido cadastrar dois clientes com o mesmo CNPJ. |
| **Dependência resolvida** | US01 entregue — projetos já existem no sistema para serem vinculados. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Restrição de acesso verificada** | Apenas o Gestor acessa as telas de cadastro e edição de clientes. |
| **Unicidade de CNPJ verificada** | O sistema impede o cadastro de dois clientes com o mesmo CNPJ. |
| **Vínculo funcionando** | Projetos vinculados a um cliente aparecem corretamente no Painel Financeiro. |

</details>

## US05 - Bloqueio de Tarefa

**User Story:** "Como Profissional, quero alterar o status de uma tarefa para bloqueada, informando obrigatoriamente a categoria do impedimento (Erro de Analista, Aguardando Cliente, Problema Técnico, Dúvida de Negócio ou Outro), para que o Gestor seja alertado e o tempo de bloqueio fique registrado."

<details>
<summary>Critérios de Aceitação</summary>

- O Profissional deve conseguir alterar o status de uma tarefa para bloqueada.
- A categoria do impedimento deve ser obrigatória ao bloquear uma tarefa.
- Ao selecionar a categoria Outro, um campo de texto livre deve aparecer e ser preenchido obrigatoriamente antes de confirmar o bloqueio.
- O sistema deve registrar automaticamente o horário de início do bloqueio.
- O Gestor deve ser alertado quando uma tarefa for bloqueada.
- O tempo total de bloqueio deve ser calculado automaticamente quando a tarefa for desbloqueada.
- O desbloqueio é feito pelo próprio Profissional.
- Uma tarefa pode ter múltiplos bloqueios ao longo do seu ciclo de vida.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Bloqueio de tarefa com sucesso**

- Dado que sou um Profissional e tenho uma tarefa com status doing;
- Quando altero o status para bloqueada e seleciono a categoria do impedimento;
- Então a tarefa deve aparecer como bloqueada e o Gestor deve ser alertado.

**Cenário 2: Tentativa de bloqueio sem categoria**

- Dado que estou bloqueando uma tarefa;
- Quando tento confirmar sem selecionar a categoria do impedimento;
- Então o sistema deve bloquear a ação e exibir mensagem de campo obrigatório.

**Cenário 3: Bloqueio com categoria Outro**

- Dado que estou bloqueando uma tarefa e seleciono a categoria Outro;
- Quando tento confirmar sem preencher o campo de descrição livre;
- Então o sistema deve bloquear a ação e exibir mensagem de campo obrigatório.

**Cenário 4: Desbloqueio e registro de tempo**

- Dado que uma tarefa está bloqueada;
- Quando o Profissional desbloqueia a tarefa;
- Então o sistema deve registrar o tempo total de bloqueio e retornar a tarefa para doing.

</details>

<details>
<summary>Regras de Negócio</summary>

- Apenas tarefas com status doing podem ser bloqueadas.
- A categoria do impedimento é obrigatória ao bloquear — bloqueio sem categoria não é permitido.
- Ao selecionar a categoria Outro, a descrição livre é obrigatória.
- O tempo de bloqueio é registrado automaticamente pelo sistema.
- O desbloqueio é feito pelo próprio Profissional.
- Uma tarefa pode ter múltiplos registros de bloqueio ao longo do seu ciclo de vida.
- O histórico de bloqueios fica registrado na tarefa para consulta futura.

</details>

## Dicionário de Dados — US05

### Bloqueio de Tarefa

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| id | Identificador único do bloqueio | Integer | - | PK, Not Null |
| tarefaId | Tarefa bloqueada | Integer | - | FK, Not Null |
| categoriaImpedimento | Categoria do impedimento selecionada | Enum | - | ERRO_DE_ANALISTA, AGUARDANDO_CLIENTE, PROBLEMA_TECNICO, DUVIDA_DE_NEGOCIO, OUTRO |
| descricaoImpedimento | Descrição livre do impedimento | String | 1000 | Not Null quando categoriaImpedimento = OUTRO |
| dataInicioBloqueio | Horário em que o bloqueio foi registrado | Timestamp | - | Not Null |
| dataFimBloqueio | Horário em que o bloqueio foi encerrado | Timestamp | - | Nullable |
| tempoBloqueio | Tempo total de bloqueio calculado em minutos | Integer | - | Nullable, Calculado |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Categorias de impedimento definidas** | Confirmadas as cinco categorias: Erro de Analista, Aguardando Cliente, Problema Técnico, Dúvida de Negócio e Outro. A categoria Outro exige descrição livre obrigatória. |
| **Regra de desbloqueio definida** | Confirmado que o desbloqueio é feito pelo próprio Profissional. |
| **Regra de tempo de bloqueio definida** | Confirmado que o sistema registra automaticamente o início e calcula o tempo total ao desbloquear. |
| **Dependência resolvida** | US4 entregue — tarefas já existem no sistema com status doing para serem bloqueadas. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Categoria obrigatória verificada** | Não é possível bloquear uma tarefa sem selecionar a categoria do impedimento. |
| **Campo livre obrigatório para Outro verificado** | Ao selecionar Outro, não é possível confirmar o bloqueio sem preencher a descrição. |
| **Tempo de bloqueio calculado corretamente** | O tempo registrado corresponde ao intervalo entre o início e o fim do bloqueio. |
| **Desbloqueio pelo Profissional funcionando** | O Profissional consegue desbloquear a tarefa e ela retorna para status doing. |
| **Histórico de bloqueios registrado** | Múltiplos bloqueios de uma mesma tarefa ficam registrados e acessíveis no histórico. |

</details>

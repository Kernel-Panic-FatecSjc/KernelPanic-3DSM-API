## US09 — Painel Financeiro

**User Story:** "Como Financeiro, quero visualizar o custo real acumulado de cada projeto comparado ao valor contratado e o detalhamento de custo por profissional, para ter base confiável para análise e faturamento."

<details>
<summary>Critérios de Aceitação</summary>

- O Financeiro deve visualizar todos os projetos com custo real acumulado, valor contratado e status (Acima, Próximo, Dentro).
- Projetos acima do valor contratado devem exibir alerta visual destacado.
- O Financeiro deve conseguir visualizar o custo gerado por cada profissional dentro de um projeto, com horas aprovadas e custo calculado.
- O Financeiro deve conseguir filtrar por projeto e período.
- A tela é somente leitura.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Visualização dos projetos**

- Dado que sou um Financeiro e acesso o painel financeiro;
- Quando visualizo a listagem de projetos;
- Então devo ver cada projeto com seu custo real acumulado, valor contratado e status (Acima, Próximo, Dentro).

**Cenário 2: Projeto acima do orçamento**

- Dado que o custo real acumulado de um projeto ultrapassou o valor contratado;
- Quando acesso o painel financeiro;
- Então o projeto deve exibir alerta visual destacado indicando que está acima do orçamento.

**Cenário 3: Custo por profissional**

- Dado que acesso o detalhamento de um projeto no painel financeiro;
- Quando visualizo o custo por profissional;
- Então devo ver as horas aprovadas e o custo calculado de cada profissional alocado no projeto.

**Cenário 4: Filtro por período**

- Dado que acesso o painel financeiro;
- Quando filtro por um período específico;
- Então o custo exibido deve considerar apenas as horas aprovadas dentro daquele período.

</details>

<details>
<summary>Regras de Negócio</summary>

- Apenas o Financeiro tem acesso ao painel financeiro.
- O custo real é calculado como somatória de (horas aprovadas × valor/hora) por profissional por projeto.
- Apenas horas aprovadas pelo Gestor entram no cálculo do custo real.
- O valor contratado é informado pelo Gestor no cadastro do projeto.
- O sistema não bloqueia projetos acima do orçamento — apenas destaca visualmente.
- A tela é somente leitura.

</details>

<details>
<summary>Dicionário de Dados</summary>

## Dicionário de Dados — US09

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| id_projeto | Projeto analisado | Integer | - | FK, Not Null |
| valor_contratado | Valor contratado cadastrado no projeto | Decimal | (15,2) | Not Null |
| custo_real_acumulado | Somatória de horas aprovadas × valor/hora por profissional | Decimal | (15,2) | Calculado |
| status_orcamento | Indicador de saúde financeira | Enum | - | DENTRO, PROXIMO, ACIMA |
| id_profissional | Profissional alocado no projeto | Integer | - | FK, Not Null |
| horas_aprovadas | Total de horas aprovadas do profissional no projeto | Integer | - | Calculado, em minutos |
| custo_por_profissional | Custo gerado pelo profissional no projeto | Decimal | (15,2) | Calculado |
| periodo_referencia | Período filtrado para o cálculo | Timestamp | - | Nullable |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Fórmula de custo real definida** | Confirmado que custo real = somatória de (horas aprovadas × valor/hora) por profissional por projeto. |
| **Custo por profissional definido** | Confirmado que o painel exibe horas aprovadas e custo calculado por profissional. |
| **Status de orçamento definido** | Confirmados os três status: Dentro, Próximo e Acima. |
| **Dependências resolvidas** | US1 e US3 entregues — valor/hora dos profissionais e horas aprovadas já existem no sistema. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Cálculo de custo real correto** | O custo exibido corresponde à somatória de horas aprovadas × valor/hora por profissional. |
| **Custo por profissional correto** | Horas aprovadas e custo de cada profissional estão calculados corretamente. |
| **Status de orçamento correto** | O status exibido corresponde à relação real entre custo acumulado e valor contratado. |
| **Destaque visual funcionando** | Projetos acima do valor contratado aparecem com alerta visual destacado. |
| **Filtro por período correto** | O cálculo considera apenas horas aprovadas dentro do período selecionado. |

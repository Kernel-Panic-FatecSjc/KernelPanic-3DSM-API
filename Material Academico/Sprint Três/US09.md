## US09 — Dashboard por Perfil

**User Story:** "Como usuário do sistema, quero acessar um dashboard personalizado de acordo com o meu perfil, para visualizar de forma consolidada as informações mais relevantes para a minha função e tomar decisões com base em dados."

<details>
<summary>Critérios de Aceitação</summary>

- Cada perfil deve visualizar apenas os indicadores definidos para sua função.
- O dashboard deve ser exibido automaticamente conforme o perfil do usuário autenticado.
- Os dados exibidos devem refletir o estado atual do sistema.
- O dashboard é somente leitura — não permite edição de dados.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Profissional acessa dashboard**

- Dado que sou um Profissional autenticado;
- Quando acesso o dashboard;
- Então devo ver meu total de horas lançadas no mês, horas por status, distribuição por tipo de atividade.

**Cenário 2: Gestor acessa dashboard**

- Dado que sou um Gestor autenticado;
- Quando acesso o dashboard;
- Então devo ver a taxa de aprovação de lançamentos por profissional e as horas por tipo de atividade por profissional.

**Cenário 3: Financeiro acessa dashboard**

- Dado que sou um Financeiro autenticado;
- Quando acesso o dashboard;
- Então devo ver o aviso de projetos acima do orçamento, a evolução do custo real acumulado comparado ao valor contratado e a previsão de faturamento do período selecionado.

</details>

<details>
<summary>Regras de Negócio</summary>

- O dashboard é personalizado automaticamente de acordo com o perfil do usuário autenticado.
- Cada perfil visualiza apenas os dados pertinentes à sua função.
- Os dados do dashboard são calculados a partir das informações já existentes no sistema.
- O dashboard é somente leitura — não permite edição de dados.
- O cálculo do custo real considera o tipo de contrato de cada profissional: CLT usa valor mensal ÷ 220h, PJ horas fixas usa valor mensal ÷ 160h, PJ horas variáveis usa o valor/hora diretamente.
- Os filtros de projeto e período são globais — atualizam todos os indicadores do dashboard do Financeiro simultaneamente.

</details>

## Dicionário de Dados — US10

### Dashboard do Profissional

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| idUsuario | Profissional autenticado | Integer | - | FK, Not Null |
| totalHorasMes | Total de horas lançadas no mês selecionado em minutos | Integer | - | Calculado |
| horasPorStatusSemana | Horas lançadas por semana separadas por status (aprovado, aguardando, rejeitado) | JSON | - | Calculado |
| horasPorStatusMes | Horas lançadas por mês separadas por status | JSON | - | Calculado |
| distribuicaoPorAtividade | Proporção de horas por tipo de atividade | JSON | - | Calculado |
| periodoReferencia | Mês ou semana selecionado para os filtros | Date | - | Nullable |

### Dashboard do Gestor

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| idProfissional | Profissional exibido na tabela | Integer | - | FK, Not Null |
| taxaAprovacao | Percentual de lançamentos aprovados por profissional | Decimal | (5,2) | Calculado |
| taxaAguardando | Percentual de lançamentos aguardando aprovação | Decimal | (5,2) | Calculado |
| taxaRejeitados | Percentual de lançamentos rejeitados | Decimal | (5,2) | Calculado |
| horasPorAtividadeProfissional | Horas lançadas por profissional separadas por tipo de atividade | JSON | - | Calculado |
| periodoReferencia | Semana ou mês selecionado para os filtros | Date | - | Nullable |

### Dashboard do Financeiro

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| idProjeto | Projeto analisado | Integer | - | FK, Not Null |
| statusOrcamento | Indicador de saúde financeira do projeto | Enum | - | DENTRO, PROXIMO, ACIMA |
| custoRealAcumulado | Custo real acumulado ao longo do tempo, calculado com base no tipo de contrato de cada profissional | Decimal | (15,2) | Calculado |
| valorContratado | Valor contratado do projeto | Decimal | (15,2) | Not Null |
| previsaoFaturamento | Total previsto a ser faturado no período selecionado | Decimal | (15,2) | Calculado |
| tipoContrato | Tipo de contrato do profissional usado no cálculo do custo | Enum | - | CLT, PJ_HORAS_FIXAS, PJ_HORAS_VARIAVEIS |
| periodoReferencia | Semana ou mês selecionado para os filtros | Date | - | Nullable |

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Indicadores por perfil definidos** | Confirmado quais métricas cada perfil visualiza no dashboard. |
| **Regra de personalização definida** | Confirmado que o dashboard é exibido automaticamente conforme o perfil autenticado. |
| **Regra de cálculo de custo definida** | Confirmado como o custo/hora é calculado por tipo de contrato (CLT, PJ horas fixas, PJ horas variáveis). |
| **Dependências resolvidas** | Todas as US anteriores entregues — os dados que alimentam o dashboard já existem no sistema. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Personalização por perfil correta** | Cada perfil visualiza apenas os indicadores definidos para sua função. |
| **Dados calculados corretamente** | Os indicadores exibidos correspondem aos dados reais do sistema sem inconsistências. |
| **Cálculo de custo por tipo de contrato validado** | O custo real do Financeiro considera corretamente CLT ÷ 220h, PJ fixo ÷ 160h e PJ variável direto. |
| **Filtros globais funcionando** | Filtros de projeto e período atualizam todos os indicadores do Financeiro simultaneamente. |
| **Isolamento de dados verificado** | Profissional não visualiza dados de outros profissionais. |

</details>

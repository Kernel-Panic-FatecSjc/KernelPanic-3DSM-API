## MVP — Minimum Viable Product

### Sprint 3 — Rastreabilidade e dados financeiros

Com a terceira Sprint, o sistema entrega visibilidade completa sobre o histórico e os custos: o Gestor acessa um painel de rastreabilidade com o consolidado de bloqueios por projeto e o histórico cronológico detalhado de cada tarefa. O Financeiro acompanha o histórico de alterações em lançamentos aprovados para garantir auditoria e base confiável para faturamento. Todos os perfis passam a contar com um dashboard personalizado com os indicadores mais relevantes para sua função — incluindo para o Financeiro o acompanhamento do custo real acumulado por projeto comparado ao valor contratado, aviso de orçamento e previsão de faturamento calculada com base no tipo de contrato de cada profissional.

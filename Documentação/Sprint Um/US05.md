## US05 - Sinalização de Bloqueios e Gestão de Gargalos

**User Story:** "Como Desenvolvedor, quero alterar o status de uma tarefa para 'Bloqueada', selecionando obrigatoriamente a categoria do impedimento (Erro de Analista, Aguardando Cliente, Problema Técnico ou Dúvida de Negócio), para que o sistema registre automaticamente o tempo de parada, calcule o custo do atraso com base no meu valor/hora e alerte o gestor no dashboard quando o bloqueio ultrapassar 24 horas, permitindo identificar e resolver gargalos com precisão financeira."

<details>
<summary>Critérios de Aceitação</summary>

- Ao alterar o status de uma tarefa para "Bloqueada", o sistema deve obrigatoriamente abrir um modal para seleção da categoria: Erro de Analista, Aguardando Cliente, Problema Técnico ou Dúvida de Negócio.
- O sistema deve registrar automaticamente o Timestamp (data, hora, minuto) no momento em que a tarefa entra em bloqueio e no momento em que ela retorna para "In Progress".
- Tarefas que permanecerem no status "Bloqueada" por mais de 24 horas consecutivas devem ser destacadas automaticamente no Dashboard do Gestor com um alerta de urgência.
- O sistema deve gerar um campo de "Custo do Atraso", que multiplica o tempo total de bloqueio pelo valorHora do desenvolvedor, exibindo esse valor em reais (R$) nos relatórios de projeto.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Ativação de Bloqueio**
- Dado que sou um Desenvolvedor e estou com a tarefa "Integração API" aberta;
- Quando eu altero o status para "Bloqueada" e seleciono o motivo "Aguardando Cliente";
- Então o sistema deve salvar o registro, iniciar a contagem do tempo de bloqueio (Timestamp) e exibir uma etiqueta visual de impedimento na tarefa.

**Cenário 2: Desbloqueio e Registro de Tempo**
- Dado que uma tarefa está "Bloqueada" há exatamente 2 horas;
- Quando o Desenvolvedor move a tarefa de volta para "In Progress";
- Então o sistema deve encerrar o Timestamp de bloqueio, calcular a diferença de tempo e atualizar o histórico da tarefa com o tempo total de parada.

**Cenário 3: Alerta de Gargalo no Dashboard**
- Dado que uma tarefa foi bloqueada ontem às 08:00 e hoje já são 09:00 (passaram 25h);
- Quando o Gestor acessa o Dashboard de Controle;
- Então o sistema deve listar essa tarefa em uma seção de "Gargalos Críticos" com um indicador visual de "Atraso > 24h".

**Cenário 4: Cálculo Financeiro do Atraso**
- Dado que o desenvolvedor tem um custo de R$ 100,00/hora e sua tarefa ficou bloqueada por 5 horas;
- Quando o Gerente gera o Relatório de Saúde do Projeto;
- Então o sistema deve exibir: "Custo de Inatividade por Bloqueio: R$ 500,00".

</details>

<details>
<summary>Regras de Negócio</summary>

- Apenas o Desenvolvedor responsável pela tarefa pode alterá-la para "Bloqueada".
- A seleção da categoria de bloqueio é obrigatória — não é possível bloquear uma tarefa sem categorizar o motivo.
- O Timestamp de início é registrado automaticamente pelo sistema no momento do bloqueio.
- O Timestamp de fim é registrado automaticamente quando a tarefa retorna para "In Progress".
- O custo do atraso é calculado como: tempo total de bloqueio (em horas) x valorHora do desenvolvedor (definido na US01).
- Tarefas bloqueadas há mais de 24 horas disparam alerta automático via mensageria para o Gestor.
- O histórico de bloqueios é imutável — registros não podem ser editados ou deletados após criação.
- Uma tarefa pode ter múltiplos eventos de bloqueio ao longo do seu ciclo de vida.
- O custo acumulado de todos os bloqueios de uma tarefa é somado e exibido no relatório do projeto.

</details>

<details>
<summary>Dicionário de Dados</summary>

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| id_bloqueio | Identificador único do evento de bloqueio | UUID | - | PK, Not Null |
| id_tarefa | Referência à tarefa bloqueada | UUID | - | FK, Not Null |
| categoria_bloqueio | Motivo do impedimento | Enum | - | Not Null [ERRO_ANALISTA, AGUARDANDO_CLIENTE, PROBLEMA_TECNICO, DUVIDA_NEGOCIO] |
| data_hora_inicio | Timestamp de início do bloqueio | Timestamp | - | Not Null |
| data_hora_fim | Timestamp de fim do bloqueio | Timestamp | - | Nullable |
| custo_atraso_acumulado | Valor em R$ calculado (horas x valorHora) | Decimal | (15,2) | Nullable |
| comentario_bloqueio | Descrição opcional do motivo | Text | - | Opcional |

</details>

## US05 - Bloqueio de Tarefa

**User Story:** "Como Profissional, quero alterar o status de uma tarefa para bloqueada, informando obrigatoriamente a categoria do impedimento (Erro de Analista, Aguardando Cliente, Problema Técnico ou Dúvida de Negócio), para que o Gestor seja alertado e o tempo de bloqueio fique registrado."

<details>
<summary>Critérios de Aceitação</summary>

- O Profissional deve conseguir alterar o status de uma tarefa para bloqueada.
- A categoria do impedimento deve ser obrigatória ao bloquear uma tarefa.
- O sistema deve registrar automaticamente o horário de início do bloqueio.
- O Gestor deve ser alertado quando uma tarefa for bloqueada.
- O tempo total de bloqueio deve ser calculado automaticamente quando a tarefa for desbloqueada.
- Uma tarefa bloqueada só pode ser desbloqueada pelo Gestor.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Bloqueio de tarefa com sucesso**

- Dado que sou um Profissional e tenho uma tarefa com status doing;
- Quando altero o status para bloqueada e seleciono a categoria do impedimento;
- Então a tarefa deve aparecer como bloqueada e o Gestor deve ser alertado.

**Cenário 2: Tentativa de bloqueio sem categoria**

- Dado que estou bloqueando uma tarefa;
- Quando tento confirmar sem selecionar a categoria do impedimento;
- Então o sistema deve bloquear a ação e exibir mensagem de campo obrigatório.

**Cenário 3: Desbloqueio e registro de tempo**

- Dado que uma tarefa está bloqueada;
- Quando o Gestor desbloqueia a tarefa;
- Então o sistema deve registrar o tempo total de bloqueio e retornar a tarefa para doing.

</details>

<details>
<summary>Regras de Negócio</summary>

- Apenas tarefas com status doing podem ser bloqueadas.
- A categoria do impedimento é obrigatória ao bloquear — bloqueio sem categoria não é permitido.
- O tempo de bloqueio é registrado automaticamente pelo sistema.
- Apenas o Gestor pode desbloquear uma tarefa.
- Uma tarefa pode ter múltiplos registros de bloqueio ao longo do seu ciclo de vida.
- O histórico de bloqueios fica registrado na tarefa para consulta futura.

</details>

<details>
<summary>Dicionário de Dados</summary>

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| id_bloqueio | Identificador único do bloqueio | UUID | - | PK, Not Null |
| id_tarefa | Tarefa bloqueada | UUID | - | FK, Not Null |
| categoria_impedimento | Categoria do impedimento selecionada | Enum | - | Erro de Analista, Aguardando Cliente, Problema Técnico, Dúvida de Negócio |
| data_inicio_bloqueio | Horário em que o bloqueio foi registrado | Timestamp | - | Not Null |
| data_fim_bloqueio | Horário em que o bloqueio foi encerrado | Timestamp | - | Nullable |
| tempo_bloqueio | Tempo total de bloqueio calculado | Integer | - | Nullable, em minutos |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Categorias de impedimento definidas** | Confirmadas as quatro categorias: Erro de Analista, Aguardando Cliente, Problema Técnico e Dúvida de Negócio. |
| **Regra de desbloqueio definida** | Confirmado que apenas o Gestor pode desbloquear uma tarefa. |
| **Dependência resolvida** | US2 entregue — tarefas já existem no sistema para serem bloqueadas. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Categoria obrigatória verificada** | Não é possível bloquear uma tarefa sem selecionar a categoria do impedimento. |
| **Tempo de bloqueio registrado corretamente** | O sistema calcula e registra o tempo total entre o início e o fim do bloqueio. |
| **Gestor alertado** | Gestor recebe alerta ao ter uma tarefa bloqueada em um projeto sob sua responsabilidade. |

</details>

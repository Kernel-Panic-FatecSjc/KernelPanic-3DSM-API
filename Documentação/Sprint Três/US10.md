## US10 - Relatório de Bloqueios

**User Story:** "Como Gestor, quero um relatório consolidado de bloqueios por projeto, com tempo parado e categoria do impedimento, para identificar padrões recorrentes e agir preventivamente."

<details>
<summary>Critérios de Aceitação</summary>

- O Gestor deve conseguir acessar um relatório consolidado de bloqueios por projeto.
- O relatório deve exibir o tempo total parado e a categoria de cada bloqueio.
- O relatório deve permitir identificar quais categorias de impedimento ocorrem com mais frequência.
- O Gestor deve conseguir filtrar o relatório por projeto e período.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Consulta de relatório de bloqueios**

- Dado que sou um Gestor e acesso o relatório de bloqueios;
- Quando seleciono um projeto;
- Então devo ver todos os bloqueios registrados com categoria, tempo parado e data de ocorrência.

**Cenário 2: Identificação de padrão recorrente**

- Dado que um projeto teve múltiplos bloqueios da categoria Aguardando Cliente;
- Quando acesso o relatório de bloqueios;
- Então devo conseguir identificar essa categoria como a mais recorrente no projeto.

**Cenário 3: Filtro por período**

- Dado que acesso o relatório de bloqueios;
- Quando filtro por um período específico;
- Então apenas os bloqueios ocorridos naquele período devem ser exibidos.

</details>

<details>
<summary>Regras de Negócio</summary>

- Apenas o Gestor tem acesso ao relatório de bloqueios.
- O relatório exibe apenas bloqueios de projetos sob responsabilidade do Gestor.
- O tempo parado é calculado automaticamente pelo sistema a partir do registro de bloqueio.
- O relatório é somente leitura — não permite edição dos registros.

</details>

<details>
<summary>Dicionário de Dados</summary>

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| id_projeto | Projeto filtrado no relatório | UUID | - | FK, Not Null |
| id_bloqueio | Bloqueio registrado | UUID | - | FK, Not Null |
| categoria_impedimento | Categoria do bloqueio | Enum | - | Not Null |
| tempo_parado | Duração total do bloqueio | Integer | - | Not Null, em minutos |
| data_ocorrencia | Data em que o bloqueio ocorreu | Timestamp | - | Not Null |
| total_por_categoria | Contagem de bloqueios por categoria no projeto | Integer | - | Calculado |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Escopo do relatório definido** | Confirmado que o relatório exibe categoria, tempo parado e data de cada bloqueio por projeto. |
| **Dependência resolvida** | US5 entregue — bloqueios com categoria e tempo já existem no sistema. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Tempo parado calculado corretamente** | O tempo exibido no relatório corresponde ao tempo real de cada bloqueio registrado. |
| **Categorias mais recorrentes identificáveis** | O relatório permite visualizar quais categorias aparecem com mais frequência por projeto. |
| **Filtro por período correto** | Apenas bloqueios do período selecionado são exibidos no relatório. |

</details>

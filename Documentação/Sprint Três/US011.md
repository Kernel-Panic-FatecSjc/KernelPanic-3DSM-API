## US11 - Dashboard por Perfil

**User Story:** "Como usuário do sistema, quero acessar um dashboard personalizado de acordo com o meu perfil, para visualizar de forma visual e consolidada as informações mais relevantes para a minha função, permitindo acompanhar desempenho, identificar gargalos e tomar decisões com base em dados."

<details>
<summary>Critérios de Aceitação</summary>

- Cada perfil deve visualizar apenas os indicadores relevantes para sua função.
- O Profissional deve ver suas horas lançadas por semana/mês, distribuição por tipo de atividade, status dos lançamentos e tarefas atribuídas.
- O Gestor deve ver ocupação e desempenho por profissional, taxa de aprovação de lançamentos, status das tarefas por projeto e bloqueios ativos com categoria e tempo.
- O Financeiro/Administrador deve ver custo real acumulado por projeto, comparativo custo real vs valor contratado e custo por profissional.
- Os dados exibidos devem refletir o estado atual do sistema.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Profissional acessa dashboard**

- Dado que sou um Profissional autenticado;
- Quando acesso o dashboard;
- Então devo ver meus indicadores de horas, distribuição por atividade e status dos meus lançamentos.

**Cenário 2: Gestor acessa dashboard**

- Dado que sou um Gestor autenticado;
- Quando acesso o dashboard;
- Então devo ver a ocupação do time, desempenho por profissional, status das tarefas e bloqueios ativos.

**Cenário 3: Financeiro/Administrador acessa dashboard**

- Dado que sou um Financeiro ou Administrador autenticado;
- Quando acesso o dashboard;
- Então devo ver o custo real acumulado por projeto, o comparativo com o valor contratado e o custo gerado por cada profissional.

</details>

<details>
<summary>Regras de Negócio</summary>

- O dashboard é personalizado automaticamente de acordo com o perfil do usuário autenticado.
- Cada perfil visualiza apenas os dados pertinentes à sua função.
- Os dados do dashboard são calculados a partir das informações já existentes no sistema.
- O dashboard é somente leitura — não permite edição de dados.

</details>

<details>
<summary>Dicionário de Dados</summary>

## Dicionário de Dados — US11

### Dashboard do Profissional

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| idUsuario | Profissional autenticado acessando o dashboard | Integer | - | FK, Not Null |
| horasPorSemana | Total de horas lançadas por semana em minutos | Integer | - | Calculado |
| horasPorMes | Total de horas lançadas por mês em minutos | Integer | - | Calculado |
| distribuicaoPorAtividade | Proporção de horas por tipo de atividade | Enum | - | ANALISE, DESENVOLVIMENTO, TESTES, CORRECAO_BUG, FEATURE, Calculado |
| statusLancamentos | Proporção de lançamentos por estado | Enum | - | APROVADO, AGUARDANDO_APROVACAO, REJEITADO, Calculado |
| tarefasAtribuidas | Lista de tarefas atribuídas ao profissional com status atual | JSON | - | Calculado |

### Dashboard do Gestor

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| idProjeto | Projeto filtrado na visualização | Integer | - | FK, Not Null |
| idProfissional | Profissional exibido na tabela de ocupação | Integer | - | FK, Not Null |
| tarefasAtivas | Quantidade de tarefas ativas (To Do e Doing) por profissional | Integer | - | Calculado |
| ocupacao | Percentual de ocupação calculado pelo total de tarefas ativas | Decimal | (5,2) | Calculado |
| taxaAprovacao | Percentual de lançamentos aprovados por profissional | Decimal | (5,2) | Calculado |
| statusTarefasPorProjeto | Distribuição de tarefas entre TO_DO, DOING, DONE e BLOQUEADA por projeto | JSON | - | Calculado |
| bloqueiosAtivos | Lista de tarefas bloqueadas com categoria do impedimento e tempo de duração | JSON | - | Calculado |

### Dashboard do Financeiro/Administrador

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| idProjeto | Projeto analisado no dashboard | Integer | - | FK, Not Null |
| custoRealAcumulado | Somatória de horas aprovadas × salario por profissional por projeto | Decimal | (15,2) | Calculado |
| valorContratado | Valor contratado cadastrado no projeto | Decimal | (15,2) | Not Null |
| statusOrcamento | Indicador de saúde financeira do projeto | Enum | - | DENTRO, PROXIMO, ACIMA |
| custoPorProfissional | Custo gerado por cada profissional no projeto com base nas horas aprovadas | JSON | - | Calculado |
| periodoReferencia | Período filtrado para o cálculo | Date | - | Nullable |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Indicadores por perfil definidos** | Confirmado quais métricas cada perfil visualiza no dashboard. |
| **Regra de personalização definida** | Confirmado que o dashboard é exibido automaticamente conforme o perfil autenticado. |
| **Dependências resolvidas** | Todas as US anteriores entregues — os dados que alimentam o dashboard já existem no sistema. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Personalização por perfil correta** | Cada perfil visualiza apenas os indicadores definidos para sua função. |
| **Dados calculados corretamente** | Os indicadores exibidos correspondem aos dados reais do sistema sem inconsistências. |
| **Isolamento de dados verificado** | Profissional não visualiza dados de outros profissionais. |

</details>

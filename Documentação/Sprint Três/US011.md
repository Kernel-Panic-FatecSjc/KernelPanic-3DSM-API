## US11 - Dashboard por Perfil

**User Story:** "Como usuário do sistema, quero acessar um dashboard personalizado de acordo com o meu perfil, para visualizar de forma visual e consolidada as informações mais relevantes para a minha função, permitindo acompanhar desempenho, identificar gargalos e tomar decisões com base em dados."

<details>
<summary>Critérios de Aceitação</summary>

- Cada perfil deve visualizar apenas os indicadores relevantes para sua função.
- O Profissional deve ver suas horas lançadas por semana/mês, distribuição por tipo de atividade, status dos lançamentos e tarefas atribuídas.
- O Gestor deve ver ocupação e desempenho por profissional, taxa de aprovação de lançamentos, status das tarefas por projeto e bloqueios ativos com categoria e tempo.
- O Financeiro/Administrador deve ver custo real acumulado por projeto, comparativo custo real vs valor contratado, projetos próximos ou acima do orçamento e histórico de alterações com impacto financeiro.
- Os dados exibidos devem refletir o estado atual do sistema.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Profissional acessa dashboard**

- Dado que sou um Profissional autenticado;
- Quando acesso o dashboard;
- Então devo ver meus indicadores de horas, distribuição por atividade e status dos meus lançamentos.

**Cenário 2: Gestor acessa dashboard**

- Dado que sou um Gestor autenticado;
- Quando acesso o dashboard;
- Então devo ver a ocupação do time, desempenho por profissional, status das tarefas e bloqueios ativos.

**Cenário 3: Financeiro acessa dashboard**

- Dado que sou um Financeiro autenticado;
- Quando acesso o dashboard;
- Então devo ver o custo real acumulado por projeto e o comparativo com o valor contratado.

**Cenário 4: Administrador acessa dashboard**

- Dado que sou um Administrador autenticado;
- Quando acesso o dashboard;
- Então devo ver o histórico de alterações em lançamentos com impacto financeiro.

</details>

<details>
<summary>Regras de Negócio</summary>

- O dashboard é personalizado automaticamente de acordo com o perfil do usuário autenticado.
- Cada perfil visualiza apenas os dados pertinentes à sua função.
- Os dados do dashboard são calculados a partir das informações já existentes no sistema.
- O dashboard é somente leitura — não permite edição de dados.

</details>

<details>
<summary>Dicionário de Dados</summary>

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| id_usuario | Usuário autenticado acessando o dashboard | UUID | - | FK, Not Null |
| perfil | Perfil do usuário autenticado | Enum | - | Profissional, Gestor, Financeiro, Administrador |
| periodo_referencia | Período dos dados exibidos no dashboard | Timestamp | - | Nullable |
| indicadores | Conjunto de métricas calculadas por perfil | JSON | - | Calculado |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Indicadores por perfil definidos** | Confirmado quais métricas cada perfil visualiza no dashboard. |
| **Regra de personalização definida** | Confirmado que o dashboard é exibido automaticamente conforme o perfil autenticado. |
| **Dependências resolvidas** | Todas as US anteriores entregues — os dados que alimentam o dashboard já existem no sistema. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Personalização por perfil correta** | Cada perfil visualiza apenas os indicadores definidos para sua função. |
| **Dados calculados corretamente** | Os indicadores exibidos correspondem aos dados reais do sistema sem inconsistências. |
| **Isolamento de dados verificado** | Profissional não visualiza dados de outros profissionais. Gestor visualiza apenas projetos sob sua responsabilidade. |

</details>

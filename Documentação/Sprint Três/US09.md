## US09 - Painel Financeiro

**User Story:** "Como Financeiro, quero visualizar o custo real acumulado de cada projeto com base nas horas aprovadas e no valor/hora dos profissionais, comparando com o valor contratado cadastrado, para ter base confiável para análise e faturamento."

<details>
<summary>Critérios de Aceitação</summary>

- O Financeiro deve visualizar o custo real acumulado por projeto calculado a partir das horas aprovadas e do valor/hora de cada profissional.
- O sistema deve exibir o comparativo entre custo real acumulado e valor contratado do projeto.
- Projetos com custo real acumulado acima do valor contratado devem ser destacados visualmente.
- O Financeiro deve conseguir filtrar por projeto e período.

</details>

<details>
<summary>Cenários</summary>

**Cenário 1: Visualização do custo real**

- Dado que sou um Financeiro e acesso o painel financeiro;
- Quando seleciono um projeto;
- Então devo ver o custo real acumulado calculado a partir das horas aprovadas e o valor contratado para comparação.

**Cenário 2: Projeto acima do orçamento**

- Dado que o custo real acumulado de um projeto ultrapassou o valor contratado;
- Quando acesso o painel financeiro;
- Então o projeto deve estar destacado visualmente indicando que está acima do orçamento.

**Cenário 3: Filtro por período**

- Dado que acesso o painel financeiro;
- Quando filtro por um período específico;
- Então o custo exibido deve considerar apenas as horas aprovadas dentro daquele período.

</details>

<details>
<summary>Regras de Negócio</summary>

- Apenas o Financeiro tem acesso ao painel financeiro.
- O custo real é calculado como somatória de (horas aprovadas × valor/hora) por profissional por projeto.
- Apenas horas aprovadas pelo Gestor entram no cálculo do custo real.
- O valor contratado é informado manualmente pelo Gestor no cadastro do projeto.
- O sistema não bloqueia projetos acima do orçamento — apenas destaca visualmente.

</details>

<details>
<summary>Dicionário de Dados</summary>

| Nome da variável | Descrição | Tipo de dado | Tamanho | Restrição |
| :--- | :--- | :--- | :--- | :--- |
| id_projeto | Projeto analisado | UUID | - | FK, Not Null |
| valor_contratado | Valor contratado cadastrado no projeto | Decimal | (15,2) | Not Null |
| custo_real_acumulado | Somatória de horas aprovadas × valor/hora | Decimal | (15,2) | Calculado |
| status_orcamento | Indicador de saúde financeira | Enum | - | dentro, próximo, acima |
| periodo_referencia | Período filtrado para o cálculo | Timestamp | - | Nullable |

</details>

<details>
<summary>DoR — Definition of Ready</summary>

| Critério | Descrição |
| :--- | :--- |
| **Fórmula de custo real definida** | Confirmado que custo real = somatória de (horas aprovadas × valor/hora) por profissional por projeto. |
| **Regra de destaque visual definida** | Confirmado que projetos acima do valor contratado são destacados sem bloqueio. |
| **Dependências resolvidas** | US1, US3 entregues — valor/hora dos profissionais e horas aprovadas já existem no sistema. |

</details>

<details>
<summary>DoD — Definition of Done</summary>

| Critério | Descrição |
| :--- | :--- |
| **Cálculo de custo real correto** | O custo exibido corresponde exatamente à somatória de horas aprovadas × valor/hora por profissional. |
| **Destaque visual funcionando** | Projetos acima do valor contratado aparecem destacados visualmente no painel. |
| **Filtro por período correto** | O cálculo considera apenas horas aprovadas dentro do período selecionado. |

</details>

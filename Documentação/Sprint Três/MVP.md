## MVP — Minimum Viable Product

### Sprint 3 — Rastreabilidade e dados financeiros

Com a terceira Sprint, o sistema entrega visibilidade completa sobre o histórico e os custos: o Gestor acessa o histórico cronológico de cada tarefa e um relatório consolidado de bloqueios por projeto. O Administrador acompanha o histórico de alterações em lançamentos para garantir auditoria dos dados. O Financeiro visualiza o custo real acumulado por projeto comparado ao valor contratado, com base confiável para faturamento. Todos os perfis passam a contar com um dashboard personalizado com os indicadores mais relevantes para sua função.
